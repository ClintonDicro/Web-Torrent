How this works

          
Everything runs in this browser tab using WebTorrent. There is no server: torrent files, magnet links and downloaded data never leave your device except as normal BitTorrent traffic to peers.

          
Which peers can I reach?

          
Browsers cannot open raw TCP or UDP connections, so they cannot talk to ordinary BitTorrent clients (qBittorrent, Transmission, uTorrent… over TCP/uTP) and cannot use UDP/HTTP trackers or the DHT. They connect only to WebRTC peers: other WebTorrent browser tabs and desktop clients with WebTorrent support (e.g. WebTorrent Desktop, and some builds of other clients), found through WebSocket (wss://) trackers. Torrents that nobody shares over WebRTC will stay at “Finding peers”.

          
Privacy

          
WebRTC peers and the trackers you use see your IP address, just like with any BitTorrent client. A VPN that covers WebRTC traffic hides it; some browsers or extensions limit WebRTC, which may also stop torrents from working.

          
Keep the tab open

          
Downloads only run while this tab is open. Closing or reloading it stops everything, and unfinished data is discarded the next time you open the app. Mobile browsers and battery savers may pause background tabs, which also pauses downloads.

          
Where files go

          
    
            
  • Browser storage (all browsers): data is kept in this site's private browser storage until you press Save. Saving streams the file to your device without loading it all into memory (in private windows of some browsers, files above 512 MB cannot be saved).
    • 
            
  • Folder on this device (Chrome and Edge on desktop): files are written straight into a folder you choose, inside a sub-folder named after the torrent. Nothing in that folder is ever deleted by this app.
    • 
          

          
Not supported in a browser

          
    
            
  • TCP/uTP peers, UDP/HTTP trackers, DHT, PEX with desktop clients, port forwarding.
    • 
            
  • Resuming after closing the tab, and downloading in the background.
    • 
            
  • BitTorrent v2-only torrents.
